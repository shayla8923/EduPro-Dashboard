# EduPro Learner Demographics & Course Enrollment Dashboard

## Project Description
This project analyzes learner demographics and course enrollment behavior using Python, Pandas, Matplotlib, and Streamlit.

## Features
- Learner Demographics
- KPI Dashboard
- Age-wise Enrollment
- Gender-wise Course Preference
- Course Category Analysis
- Course Level Analysis
- Interactive Filters

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
